# Sango MCP 能力文档（三国演义检索）

> 版本：v1.0 ｜ 整理：Coco ｜ 日期：2026-09-20
> 当前范围：仅支持《三国演义》（`source=sanguo-yanyi`；`sanguozhi` 预留）
> 关联：feat-A004（能力与校验口径）、MCP 工具契约见总台 `api/feat-A004-sango-classics-rag.md`；语料规范见 `dev-docs/docs/sango-corpus-spec.md`

---

## 一、定位

面向编排层（总台）的原文检索工具，只返回原文，不评价、不编造。

- 只取原文：返回内容必须来自《三国演义》原文，可核对、可溯源；
- 不评价：原文怎么说就返回什么，不解读、不判断；
- 不编造：原文没有的，返回空结果，由调用方（总台）决定拒答话术。

---

## 二、暴露工具

当前只有一个工具：`sango_novel_search`

**用途**：检索《三国演义》原著原文段落。仅当调用方需要原文依据的问题时调用；回答前必须先调用本工具取得原文，禁止凭记忆作答。与题库工具（风云三国 `fengyunsanguo_query` 等）不同，本工具只检索原著文本。

**输入**：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `source` | enum | 是 | 语料来源：`sanguo-yanyi`（本期）/ `sanguozhi`（预留） |
| `query` | string | 是 | 检索关键词或句子，最小长度 1 |
| `limit` | number | 否 | 返回条数，默认 5，最大 MAX_LIMIT |

**输出**：结构化条目数组（`id` / `text` / `type` / `segFrom` / `segTo` / `quoteBalanced` / `quotes[]`，含回级 `chapter` / `title` 展开），**不返回拼接文本块、不含出处头**；出处与引用由总台服务端渲染，段号为内部字段、不下发展示。

> **`quotes[]` 出参形态（bug-00010，2026-09-21）**：出参只回 `{ offset, len }`（引语文本由 `text` 切片还原：`text.slice(offset - 1, offset - 1 + len + 2)` = `“` + 引语 + `”`）。语料 JSON 仍是 `{ qid, text, offset, speaker }`（不重建）——**出参与语料 schema 已分叉**，改契约须对账 `docs/sango-corpus-spec.md` §5 与 `mcp-orchestrator/api/feat-A004-sango-classics-rag.md`「输出（命中）」。

## 三、典型调用示例

| 输入 | 返回 |
|---|---|
| 温酒斩华雄原文怎么写的 | 第 5 回相关段落 + 回目 |

## 四、当前能力

- [ ] 常见人物、情节、出处的查询能稳定命中原文
- [ ] 能返回指定情节的原文段落，不丢关键句
- [ ] 每条结果携带回目等元数据
- [ ] 原文没有的、范围外的，返回空，不编造
- [ ] 关羽/云长/汉寿亭侯同一人物的不同叫法，都能召回
- [ ] 长段落中的关键句不被截断，完整返回
- [ ] 白话问法也能召回到原文
- [ ] 人物、事件之间的关系能查（图谱支持后）
- [ ] 答案集中在某个情节单元内时，能完整返回

> **开放式归纳暂不考虑纳入支持范围。** 例如"有哪些单挑名场面"——答案分散全书，无固定情节单元，暂不纳入规划。
